# Firebase Authentication - Quick Reference

## Files Structure

```
lib/
├── core/
│   ├── config/
│   │   └── firebase_config.dart          # Firebase initialization
│   ├── providers/
│   │   └── auth_provider.dart            # Riverpod auth providers
│   └── services/
│       └── auth_service.dart             # Firebase auth logic
├── widgets/
│   └── auth/
│       ├── login_dialog.dart             # Login UI with 3 options
│       └── email_login_form.dart         # Email sign-in/sign-up form
├── main.dart                              # Updated with Firebase init
└── widgets/common/app_bar/
    └── custom_app_bar.dart               # Updated with login/profile
```

## Key Components

### 1. AuthService (lib/core/services/auth_service.dart)

Core authentication logic:

- `signInWithGoogle()` - Google authentication
- `signInWithApple()` - Apple authentication
- `signInWithEmail(email, password)` - Email sign-in
- `signUpWithEmail(email, password, name)` - Email sign-up
- `signOut()` - Logout user
- `resetPassword(email)` - Password reset

### 2. AuthProvider (lib/core/providers/auth_provider.dart)

Riverpod providers for state management:

- `authServiceProvider` - Access AuthService
- `currentUserProvider` - Watch current user (reactive)
- `signInWithGoogleProvider` - Sign in with Google
- `signInWithAppleProvider` - Sign in with Apple
- `signInWithEmailProvider` - Sign in with email
- `signUpWithEmailProvider` - Sign up with email
- `signOutProvider` - Sign out
- `resetPasswordProvider` - Reset password

### 3. LoginDialog (lib/widgets/auth/login_dialog.dart)

Main login UI showing:

- Google sign-in button
- Apple sign-in button
- Email sign-in button
- Error messages
- Loading states

### 4. EmailLoginForm (lib/widgets/auth/email_login_form.dart)

Email authentication form:

- Email input with validation
- Password input with show/hide toggle
- Name input (for sign-up)
- Toggle between sign-in and sign-up
- Form validation (email format, password length)

## Integration with AppBar

The `CustomAppBar` now shows:

- **LogIn Button** - If user is not logged in (opens LoginDialog)
- **User Profile** - If user is logged in (shows name/initials + logout menu)

## Usage Examples

### Show Login Dialog

```dart
showDialog(
  context: context,
  builder: (context) => const LoginDialog(),
);
```

### Check Current User

```dart
final user = ref.watch(currentUserProvider);
user.when(
  data: (user) => user != null ? Text('Welcome ${user.email}') : SizedBox(),
  loading: () => CircularProgressIndicator(),
  error: (e, st) => Text('Error: $e'),
);
```

### Sign Out

```dart
await ref.read(signOutProvider(null).future);
```

## Common Tasks

### Task: Protect a route based on auth

```dart
// In your router
authStateProvider.when(
  data: (user) => user != null ? MyPage() : LoginPage(),
  loading: () => LoadingPage(),
  error: (e, st) => ErrorPage(),
)
```

### Task: Get user profile info

```dart
final user = ref.watch(currentUserProvider);
print(user.value?.email);
print(user.value?.displayName);
print(user.value?.photoURL);
```

### Task: Listen for auth changes

```dart
ref.listen(currentUserProvider, (previous, next) {
  next.whenData((user) {
    if (user != null) print('User signed in');
    else print('User signed out');
  });
});
```

### Task: Handle auth errors

```dart
try {
  await signIn();
} on FirebaseAuthException catch (e) {
  showErrorDialog(e.message ?? 'Auth failed');
}
```
